06 / PROVENANCE

Where the report comes from

$provenance_rows

Reading this report responsibly

Metadata charts and embeddings may use different bounded row samples. Every view states its denominator. Non-finite coordinates are excluded from plots; their metadata still contributes to metadata summaries. Missing annotation values remain a separate composition group.

File size and modification-time checks are recorded, but no full-file checksum is computed. An absence of warnings is not proof of integrity or scientific quality.

This HTML contains source paths, selected metadata and embedding coordinates. It is self-contained and works without network access; share it with the same care as those annotations.
